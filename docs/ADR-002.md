# ADR-002 — Redis Cache + RabbitMQ Broker

Accepted.

Redis is the hot cache/state layer and never canonical storage.

RabbitMQ is the primary operational broker for call dispatch, retries, async jobs, event fan-out and DLQ/reprocessing.

PostgreSQL remains authoritative and uses Transactional Outbox for critical events.

Redis/RabbitMQ must not carry PCM/audio frames.
